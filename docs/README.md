# Project Documentation

This folder will contain documentation for our MxV Rail wheel profile
and hunting analysis. We will use it to explain our data, record
decisions, and help others understand and reproduce our work.

## Planned Documentation

- Data dictionary: variable definitions, measurement units, and identifiers.
- Data relationships: how wheel measurements, profiles, and simulation
  results connect across files.
- Methods: data cleaning steps, feature calculations, and analysis assumptions.
- Meeting notes: decisions, assigned tasks, and follow-up items.
- Open questions: uncertainties that need clarification from our team,
  instructors, or community partner.
- Reports: project milestones and final reports approved for this repository.

## File Naming

Use descriptive filenames without spaces, such as:

- data_dictionary.md
- analysis_methods.md
- open_questions.md
- meeting_notes_2026_09_18.md

These are naming examples, not files that have already been created.

## Recording Questions and Decisions

For each open question, explain what is unclear, why it matters,
and which analysis depends on the answer. Record the resolution
when it becomes available.

Distinguish confirmed information from assumptions, and continue
work that does not depend on unresolved questions.

## Confidentiality

Only include materials permitted by the project's agreements.
Do not upload restricted datasets, signed agreements, credentials,
or confidential partner documents.
