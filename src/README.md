# Source Code

This folder will contain reusable Python code for our MxV Rail
wheel profile and hunting analysis.

As the project develops, we will add code for:

- Loading wheel profile measurements and simulation results
- Checking data quality and joining datasets
- Calculating wheel profile shape features
- Analyzing relationships between wheel characteristics and hunting
- Creating visualizations to communicate our findings

Use descriptive filenames without spaces and relative file paths.
Document each script's purpose, required inputs, and outputs.

Exploratory notebooks belong in notebooks/. Restricted datasets
should remain in the local data/ folder, which is excluded from Git.
